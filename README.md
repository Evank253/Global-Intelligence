# KCN Intelligence OS v4

> **A Modular Multi-Layer Intelligence Architecture (KCN v4: From Core Kernel to Global Intelligence Network Layer)**

KCN Intelligence OS v4 is a distributed operational research and production network for verifiable multi-agent reasoning, cross-domain knowledge transfer, independent holdout validation, digital twin simulation, federated node consensus, and global compute cluster scheduling.

## ⚡ Quick Start

### 1. Execute v4 Master Network Single File Bundle
Run the self-contained master system:
```bash
python kcn_master_system.py
```

### 2. Execute Full Demonstrator Pipeline
Run the multi-node reasoning demonstrator:
```bash
python main.py
```

### 3. Run Test Matrix
Run the complete suite of 145 unit, safety, benchmark, and v4 network tests:
```bash
pytest
```

### 4. Launch Enterprise Server & Dashboard Portal
Start the FastAPI application server:
```bash
python api/server.py
```
Open in browser:
- **Command Dashboard:** `http://localhost:8000/dashboard`
- **Interactive OpenAPI Specs:** `http://localhost:8000/docs`
- **Health Telemetry:** `http://localhost:8000/health`
